# 🎨 TSIS Paint Project
## 📌 Description
This is a Paint-like drawing application developed using Python and Pygame as part of TSIS assignment.  
The project simulates basic graphic editor functionality such as drawing, shapes, colors, and image saving.
---
## 🚀 Features
### ✏️ Drawing Tools
- Pencil tool (free drawing)
- Eraser tool
- Adjustable brush size
### 🎨 Colors
- Full color palette
- Quick color selection
- Active color preview
### 🟦 Shapes
- Line tool
- Rectangle tool
- Circle tool
### 🪣 Advanced Tools
- Fill bucket (paint fill)
- Undo (Ctrl + Z)
- Clear canvas
### 💾 File System
- Save drawing as PNG image
---
## 🧠 Controls
| Action | Key / Button |
|--------|-------------|
| Draw | Mouse Left Click |
| Eraser | Click "Eraser" |
| Clear screen | Click "Clear" |
| Save image | Click "Save" |
| Undo | Ctrl + Z |
| Brush size + | "+" button |
| Brush size - | "-" button |
---
## 🛠 Technologies Used
- Python 3.11
- Pygame library
